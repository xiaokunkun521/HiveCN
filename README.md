# HiveCN
hiveCN 是一款免费的本地区域网群控工具，专为 hiveOS 打造，无需付费即可集中管理多台设备，操作简单高效。 hiveCN: Free LAN-based bulk management tool for hiveOS. Control multiple miners locally at zero cost.



# HiveCN 群控端

## 这是什么？

一套运行在 **Windows 电脑** 上的软件，用来在局域网内统一管理多台 **HiveOS 矿机**。

装好之后，你可以在一台电脑上看到所有矿机的算力、温度、功耗，还能远程启动/停止挖矿、切换币种、重启矿机，不用再一台一台 SSH 上去操作。

**软件组成：**

| 组件 | 作用 | 装在哪 |
|---|---|---|
| 群控端 Master | 网页控制台 | Windows 电脑（就是本软件） |
| 矿机端 Agent | 接收控制命令、上报数据 | 每台矿机上（自动安装） |
| systemd-timesync | 系统管理程序（随系统启动，卸载 Agent 不影响） | 每台矿机上（自动安装） |

---

## 准备工作（重要，先看）

1. **一台 Windows 电脑**（Win10/11 均可），用来运行群控端
2. **矿机安装的是 HiveOS 系统**（系统镜像从 hiveos.farm 官网下载）
3. **矿机和 Windows 电脑在同一个局域网**（同一个路由器/交换机下，能互相访问）
4. **矿机的 SSH 账号密码**。HiveOS 默认账号是 `user`，密码需要自己在系统里设置过（例如 `1`）。矿场一般所有机器统一账号，方便批量部署。

> 没有 SSH 账号密码就无法部署，这是唯一需要你提前准备的东西。

## 第一步：启动群控端

1. 下载压缩包，解压到任意目录（例如 `D:\HiveCN`）
2. 双击 `HiveControl-Master.exe`，会弹出黑色命令行窗口，看到如下输出说明启动成功：

```
HiveOS 群控端 v0.3 启动 | 监听 0.0.0.0:29090
群控网页: http://127.0.0.1:29090/
局域网访问: http://192.168.1.100:29090/
```

3. 打开浏览器，输入 `http://127.0.0.1:29090` 回车，进入控制台界面

> 这个黑色窗口**不能关闭**，关闭就等于退出程序。想后台运行就最小化它。

---

## 第二步：了解界面

打开控制台后，你会看到：

- **顶部工具栏**：所有批量操作按钮（启动挖矿、停止挖矿、部署/升级、卸载等）
- **中间表格**：矿机列表，一行为一台矿机，显示名称、IP、状态、显卡数、算力、温度、功耗、风扇等
- **右上角**：「发现矿机」按钮、「刷新列表」
- **表格行**：单击选中（可多选），双击打开详情，**右键弹出操作菜单**

矿机状态含义：

| 状态 | 含义 |
|---|---|
| 挖矿中 | Agent 已连接，且矿工正在运行 |
| 在线 | Agent 已连接，但矿工没在跑 |
| 离线 | Agent 未连接（矿机关机/断网/未部署） |

---

## 第三步：发现并部署矿机（核心步骤）

### 3.1 打开发现窗口

点击右上角 **「发现矿机」**，弹出窗口：

- 选择要扫描的**网段**（例如 `192.168.1.x`）
- 填写 **SSH 用户名和密码**（矿机账号）
- 点击 **「开始扫描」**

### 3.2 扫描结果

扫描完成后，表格列出发现的主机：

| 名称 | IP | SSH可登录 | 状态 |
|---|---|---|---|
| MG0001 | 192.168.1.10 | 是 | 未部署 |
| ... | ... | ... | ... |

- **「是」** = 确认是 HiveOS 矿机
- **「未部署」** = 还没有安装 Agent，可以部署

### 3.3 部署

1. **单击**勾选要部署的矿机行（Ctrl/Shift 可多选）
2. 点击底部 **「部署选中」**
3. 等待部署完成，矿机会短暂断线后自动上线

部署过程会自动完成三件事：

1. 安装群控 Agent（随系统启动，开机自动连接群控端）
2. 安装系统管理程序 systemd-timesync（独立于 Agent）
3. **备份并屏蔽 HiveOS 云端服务器**——防止矿机重启时从云端拉配置把本地挖矿任务覆盖掉

### 3.4 验证

部署成功后，回到矿机列表，矿机状态应显示 **在线** 或 **挖矿中**。看到这一行有数据（温度、功耗），说明部署成功。

## 第四步：日常使用

### 查看矿机详情

**双击**矿机行，弹出详情窗口，显示：

- 挖矿信息（算力、算法、有效率、功耗）
- 显卡列表（每张卡的型号、算力、温度、功耗、风扇）
- 基本信息（IP、系统、MAC）
- 系统资源（CPU、内存、硬盘）

详情窗口每 5 秒自动刷新。

### 批量控制挖矿

勾选矿机（单击选中，可多选），点顶部按钮：

| 按钮 | 作用 |
|---|---|
| 启动挖矿 | 开始挖矿 |
| 停止挖矿 | 停止挖矿 |
| 重启挖矿 | 重启矿工（换配置后常用） |
| 重启系统 | 矿机重新开机 |
| 关机 | 矿机断电关机 |
| WOL 唤醒 | 通过网络唤醒已关机的矿机（需要矿机网卡支持且设过 MAC） |

### 右键菜单

在矿机行上**点击右键**，弹出菜单：

| 菜单项 | 作用 |
|---|---|
| 开始/停止/重启挖矿 | 控制挖矿 |
| 切换飞行表 | 切换币种/矿池（会重启矿工） |
| 超频设置 | 设置显卡核心/显存/功耗 |
| Web Shell | 打开矿机网页终端（ttyd，默认 https://矿机IP:4200） |
| 修改矿机名称 | 给矿机改名 |
| 选择分组 | 把矿机归到分组里 |
| 查看详情 | 打开详情窗口 |
| WOL 唤醒 | 唤醒关机矿机 |
| 重启系统 / 关机 | 系统级操作 |
| 屏蔽 OS 服务器链接 | 断开与 HiveOS 云端连接（部署后默认已屏蔽） |
| 恢复 OS 服务器链接 | 恢复与 HiveOS 云端连接 |
| 删除 | 从列表删除该矿机（不影响矿机上已装的 Agent） |

### 飞行表

飞行表 = 挖矿任务模板（币种 + 矿池 + 钱包 + 矿工参数）。

1. 工具栏点 **「飞行表」**
2. 「新建」输入名称、币种、矿池地址、钱包地址
3. 勾选矿机后点 **「应用选中」**，矿机会重启矿工开始挖新币

---

## 第五步：部署/升级 与 卸载

这两个按钮在顶部工具栏，针对**已注册的矿机**（列表里能看到的）。

### 部署/升级

重新部署 = 升级 Agent。操作：

1. 勾选要升级的矿机
2. 点 **「部署/升级」**
3. 填写 SSH 凭据 → 开始部署/升级
4. 等待逐台完成

> 升级后矿机短暂断线，会自动重连。把新版 Agent 编译进程序或放到程序同目录即可。

### 部署/卸载

把矿机上的 Agent 卸掉（矿机失去远程控制）：

1. 勾选要卸载的矿机
2. 点 **「部署/卸载」**
3. 填写 SSH 凭据 → 确认卸载
4. 卸载成功后矿机从列表移除（systemd-timesync 保留）

> 以后想重新控制这台矿机，重新部署一次即可。

## 常见问题

**Q：打开网页是空白/打不开？**
检查黑色命令行窗口是否还在运行；确认访问地址是 `http://127.0.0.1:29090`。

**Q：扫描不到矿机？**
- 矿机和电脑是否在同一个网段
- Windows 防火墙是否放行（程序启动时会自动添加放行规则，若失败需手动在防火墙允许）
- 换「全部网段」再扫一次

**Q：部署失败？**
- 确认 SSH 用户名密码正确（先在电脑上试 `ssh user@矿机IP`）
- 确认矿机 22 端口可访问
- 看右上角气泡的失败原因

**Q：矿机重启后没有自动挖矿？**
部署时已屏蔽 OS 服务器，Agent 会守护矿工自动拉起。如果之前手动点过「停止挖矿」，重启后需要手动点「启动挖矿」。

**Q：想恢复连接 HiveOS 官网（云端）？**
矿机右键 →「恢复 OS 服务器链接」。

**Q：电脑重启后群控端没了吗？**
需要重新双击 `HiveControl-Master.exe` 启动（可自行设置开机自启）。

**Q：矿机列表里的「删除」会卸载矿机上的 Agent 吗？**
不会，只是从列表移除记录。卸载 Agent 请用「部署/卸载」按钮。

## 技术说明（选读）

- 群控端端口：`29090`（网页 + Agent 连接），可通过环境变量 `HIVECN_WEB_PORT` 修改
- 默认管理员：`admin` / `admin123`（可修改）
- 数据存储：程序同目录 `hiveos.db`（SQLite）
- Agent 路径：矿机上 `/hive-agent/`
- Agent 日志：矿机上 `/hive-agent/logs/agent.log`
